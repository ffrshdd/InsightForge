## ✨ Features

- 📄 Upload PDF, DOCX, TXT, Markdown, JSON, CSV
- 🧠 Semantic search using FAISS + Sentence Transformers
- 🤖 AI-powered Q&A via Google Gemini 2.5 Flash
- 💬 Chat history with conversation view
- 🔍 Search history on Home dashboard
- 📊 Analytics dashboard with file type charts
- 📂 Document Manager with delete and auto-reindex
- 📄 Source citations showing exact filename per chunk
- ⬇ Export answers as TXT or Markdown
- 🎨 Material-inspired dark UI
